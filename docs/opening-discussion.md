# Try Commercial Electrical Case Study Builder and share what would make it more useful

This free browser tool is for commercial electrical contractors. Write a useful project example from the work you actually delivered, ready to check before it goes on your website.

[Open the tool](https://electrician-web-design.github.io/electrical-project-story-builder/). No coding knowledge, installation or account is needed. Start with the fictional example, or fill in the labelled fields with your own information. A structured project story and a short publication checklist.

Feedback about unclear questions, missing practical options or mobile usability is welcome here. Please use fictional information in public examples and keep customer or confidential details out of this discussion.

Use approved project facts only. This does not provide installation advice or verify technical safety, qualifications or compliance.
